# Nokturno pro Stremio – doplněk pro Home Assistant

Úložiště doplňků Home Assistantu s doplňkem **Nokturno pro Stremio**. Doplněk pro Stremio a Nuvio běží doma
v Home Assistantu, přihlašovací údaje ke zdrojům tak neprocházejí přes žádný cizí server.

[![Přidat úložiště do Home Assistantu](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fnokturno-app%2Fnokturno-stremio-ha)

Ručně: **Nastavení → Doplňky → Obchod s doplňky → ⋮ → Úložiště** a přidej
`https://github.com/nokturno-app/nokturno-stremio-ha`. Pak nainstaluj **Nokturno pro Stremio**.

Doplněk je pro amd64, aarch64 i armv7. Kód se stahuje při sestavení z
[vydání aplikace](https://github.com/nokturno-app/nokturno-stremio-app/releases) (ověřený SHA-256) a nové verze
si doplněk stahuje sám.

Návod: https://nokturno-app.github.io/nokturno-napoveda/cs/stremio-aplikace
